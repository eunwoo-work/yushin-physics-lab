## GitHub Pages 배포/업데이트
1. GitHub 저장소 `eunwoo-work/yushin-physics-lab`를 엽니다.
2. 이 ZIP 파일을 압축 해제합니다.
3. 압축 해제한 파일을 저장소의 최상위에 업로드하고 기존 파일을 덮어씁니다. 최상위의 `index.html`과 `guides/` 안의 HTML을 함께 반영합니다.
4. Commit changes를 누릅니다. 저장소의 Settings → Pages가 `main` 및 `/(root)`로 설정되어 있는지 확인합니다.
5. 배포 후 https://eunwoo-work.github.io/yushin-physics-lab/ 에서 확인합니다.

## 다음에 장비를 추가할 때
- 장비 카드를 `index.html`의 `equipment-grid` 안에 추가합니다.
- `guides/` 폴더에 장비별 HTML 페이지를 하나 추가합니다.
- 카드의 `href`와 안내 페이지 파일명이 일치해야 합니다.
- 장비별 사용 순서는 실제 학교 장비의 모델·단자·스위치 구성과 교사 지침을 확인한 뒤 사용하세요.

## 안전 및 정확성
전원공급장치, 고전압 유도코일, 알코올을 사용하는 안개상자, 강한 광원은 교사의 감독 아래 사용해야 합니다. 일부 모델별 조작법은 장비에 따라 다르므로 일반 안내보다 해당 모델의 설명서와 학교 안전 지침을 우선합니다. 오실로스코프의 접지, 전원공급장치의 전류 제한, 스트로보스코프의 RPM 환산 등은 실제 설정 조건을 확인해야 합니다.

GitHub Pages는 정적 웹사이트입니다. 학생은 공개 주소로 자료를 볼 수 있지만 사이트 안에서 바로 수정하는 기능은 제공하지 않습니다. 자료 수정 권한은 GitHub 저장소 접근 권한으로 통제합니다.
