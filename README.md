# 유신고 물리실험실 실험 장비 사용법

## 포함된 기능
- 모바일 대응 레이아웃
- 장비 이름/키워드 검색
- 분류별 필터
- 장비별 사용법 페이지
- 관련 자료 링크 영역

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다. 추천 이름: `yushin-physics-lab`
2. 이 폴더 안의 파일과 폴더를 저장소 최상위에 업로드합니다.
3. 저장소의 Settings → Pages로 이동합니다.
4. Build and deployment에서 Deploy from a branch를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`를 선택하고 Save를 누릅니다.
6. 배포가 완료되면 Settings → Pages에 표시되는 사이트 주소를 엽니다.

예상 주소: https://eunwoo17.github.io/yushin-physics-lab/
(저장소 이름과 GitHub 계정에 따라 달라질 수 있습니다.)

## 자료 수정
- `index.html`: 장비 카드, 검색 키워드, 분류, 링크를 수정합니다.
- `guides/` 폴더: 장비별 사용법 페이지를 수정합니다.
- 자료 링크는 학교에서 사용하는 실제 장비의 모델과 일치하는지 확인한 뒤 추가하세요.
- 자료 내용은 시작용 예시입니다. 학교의 실제 보유 장비와 교사 지침에 맞게 검토해야 합니다.

## 관리자 권한
GitHub 저장소의 Settings → Collaborators(또는 Access)에서 편집 권한이 필요한 관리자만 초대하세요. 학생에게는 공개 사이트 주소만 공유하고 저장소 쓰기 권한을 부여하지 않으면, 학생은 사이트를 볼 수 있지만 자료 파일을 수정해 배포할 수 없습니다.

중요: GitHub Pages는 정적 호스팅입니다. 이 템플릿은 사이트 내부의 관리자 로그인/수정 기능을 제공하지 않습니다. 브라우저 코드에 비밀번호를 넣어 관리자 기능을 흉내 내는 것은 안전하지 않습니다.
